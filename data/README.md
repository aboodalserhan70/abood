# مجموعة البيانات

ضع صور كل فئة في مجلدها الخاص داخل `data/raw/`:

```
data/raw/
├── Corn_Blight/        اللفحة الشمالية
├── Corn_Common_Rust/   الصدأ الشائع
├── Corn_Gray_Spot/     التبقّع الرمادي
└── Corn_Health/        أوراق سليمة
```

الصيغ المدعومة: `jpg` · `jpeg` · `png` · `bmp` · `webp`.
أسماء المجلدات أعلاه إلزامية لأنها تُستخدم لتحديد الفئات في `src/config.py`.

> العيّنة الحالية تحتوي 18 صورة فقط (5 / 3 / 5 / 5) لأغراض العرض والتحقق.
> لتشغيل التدريب الكامل، أضف بقية صور مجموعة البيانات في المجلدات نفسها.
